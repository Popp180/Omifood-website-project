# Omnifood Project 🍽️

## Project Overview

Omnifood is a responsive food subscription website developed as part of Jonas Schmedtmann's HTML and CSS course.

This project demonstrates my ability to build and structure a complete responsive website using modern front-end techniques.

## Key Features

- Responsive layout across desktop, tablet, and mobile
- Navigation and smooth scrolling
- Meal, testimonial, pricing, and CTA sections
- Responsive images and mobile navigation

## Technologies & Skills

- HTML5
- CSS3
- Flexbox & CSS Grid
- Media Queries
- Responsive Web Design
- Basic JavaScript

## What I Learned

Through this project, I strengthened my understanding of responsive layouts, reusable CSS, semantic HTML, and adapting a design across different screen sizes.
